# 第一部分：规范总则

## 1.1 建设目标

本规范用于建立一套面向小学低段语文练习卷的统一排版设计体系。

系统应当同时满足两个目标：

**目标一：出版设计质量**

- 版面整洁、层级清晰。
- 字体、字号、行距符合低年级学生阅读习惯。
- 田字格、拼音格、答题线等具有正确的几何尺寸。
- 题目之间具有合理的视觉间距。
- 纸张打印后清晰、易读、易书写。
- 学生卷和教师解析卷保持一致的内容结构。

**目标二：AI 排版工程能力**

- 题目内容可以转换为结构化数据。
- 不同题型能够自动映射到对应排版组件。
- 不同年级使用不同的设计参数。
- 系统能够计算组件尺寸和页面空间。
- 系统能够自动完成分页。
- 输出 PDF 可以进行程序化检测。
- 每次排版结果具有可追溯性。

## 1.2 核心设计原则

| 原则 | 具体要求 |
|---|---|
| 内容优先 | 不得为了节省页面空间改变题目原意 |
| 年级适配 | 一年级与二年级不能完全使用相同的字号和书写空间 |
| 书写优先 | 答题区域必须满足实际书写需求 |
| 视觉一致 | 同类型题目使用统一组件和视觉规则 |
| 分页完整 | 不允许题干、选项、答题区无规则分离 |
| 确定性排版 | 大模型不得直接决定最终坐标和分页 |
| 可验证 | 所有关键尺寸必须能够通过程序或样张验证 |
| 可扩展 | 新增年级、题型不能破坏已有组件 |

## 1.3 不属于本规范的内容

本规范不负责：

1. 题目知识点是否正确。
2. 题目是否符合教材范围。
3. 题目难度和教学目标是否合理。
4. 标准答案是否正确。
5. 试卷内容是否覆盖完整教学要求。

这些内容属于题目生成和内容审核体系。

本规范负责的是：**已经审核通过的题目，如何被正确、稳定、美观地排版输出。**

## 1.4 全局视觉与页面布局规范六层架构（L1–L6）

系统遵循“**全局规范定义统一规则，Profile 定义学段与场景差异，组件负责具体呈现**”的核心分层体系，严禁组件自行设定任意边距与字体：

# 第二部分：页面与印刷规范

## 2.1 纸张规格

默认采用 A4 纸。

| 属性 | 规格 |
|---|---|
| 纸张宽度 | 210 mm |
| 纸张高度 | 297 mm |
| 页面方向 | 纵向 |
| 默认排版模式 | 单栏 |
| 辅助排版模式 | 双栏、网格、混合布局 |
| 输出格式 | PDF |
| 默认缩放 | 100% |

页面尺寸必须使用毫米作为统一物理单位。

不允许在布局计算中混用未经换算的像素、毫米、英寸。

## 2.2 页面边距与 12 栅格体系

全局设计系统基线配置（A4 纵向）：

| 区域 | 规范基线尺寸 | 说明 |
|---|---:|---|
| 左边距 | 15 mm | 默认对称基线 / 预留装订与手持阅读呼吸感 |
| 右边距 | 15 mm | 默认对称基线 |
| 上边距 | 15 mm | 保证页眉上方留有打印机物理抓纸安全区 |
| 下边距 | 15 mm | 避开家用喷墨机（如 14.3mm）与激光机走纸盲区 |
| 边距内总空间 | 267 mm | 297mm 物理高度扣除上下各 15mm 边距后的净空间 |
| 页脚占用区 | 8 mm | 页脚文字高 5mm + 与内容区安全呼吸留白 3mm |
| 版心可用高度 | 259.0 mm | 正文内容区实际可用排版高度（267mm - 8mm 页脚占用） |
| 版心宽度 | 180 mm | 12 栅格总宽（12 列 × 11.333mm + 11 间距 × 4mm） |

> [!NOTE] **可用高度 259mm 与边距内总空间 267mm 的工程定义**
> 1. **边距内总空间 (Margin Box)**：$297\text{mm} - 15\text{mm}(\text{top}) - 15\text{mm}(\text{bottom}) = 267.0\text{mm}$。
> 2. **页脚区域 (Footer Area)**：包含页脚文字（高 5mm）以及页脚与正文内容之间的安全缓冲区（3mm），固定占用 $8.0\text{mm}$。
> 3. **正文内容区预算 (Usable Content Box)**：因此排版引擎的单页装箱预算为 $267.0\text{mm} - 8.0\text{mm} = 259.0\text{mm}$。
> 4. **首页 vs 后续页差异**：
>    - **首页**：需扣除试卷主标题、学生信息栏（姓名/班级/准考证/得分槽）及考查说明等试卷头模板（占高约 $35\sim 50\text{mm}$），首页正文内容实际可用高度约为 $209\sim 224\text{mm}$。
>    - **后续页**：页眉置于上方 $8\text{mm}$ 抓纸安全带中，不侵占版心，享有满额 $259.0\text{mm}$ 正文预算。

### 12 栅格体系
版心（180mm）划分为 12 个等宽栅格，列间距（Gutter）统一为 4mm：
- 单列宽：11.333 mm
- `col-12`：180 mm（整行通栏，如阅读文章、看图写话答题格、古诗填空）
- `col-6`：88 mm（半行双栏，如形近字组词、多音字辨析、选择题）
- `col-4`：57.33 mm（三分之一行，如成语短槽、看拼音写词语 3 组/行）
- `col-3`：42 mm（四分之一行，如短词、拼音字母书写）

上述数值是设计系统基线，若实际硬件设备存在不对称盲区或需要特殊装订槽，可通过硬件打印机 Profile（`--printer <profile>` 或 `--margin-bottom <mm>`）参数化动态补偿。

不得为了追求单页容纳率，将全局上下边距压缩到未经验证的极限值。

## 2.3 页面模板与结构规范

试卷分为两种模板页面：
1. **首页模板（First Page）**：
   - **试卷头区域（Title Area）**：包含主标题（`21~22pt`）、副标题（`13~14pt`，可选）、学生信息栏（姓名/班级/准考证号/得分栏，带有 0.22mm 细下划线）、试卷说明与考试须知（`11~12pt`）。
   - **题目内容区**：试卷头下方 `spacing-5`（8mm）进入大题。
   - 首页不显示流式页眉。
2. **后续页模板（Subsequent Running Pages）**：
   - **流式页眉（Running Header）**：位于版心上方安全带（`y ≈ 8mm`，底边距版心顶端 3mm），包含试卷主标题、副标题、学段标识及 0.18mm 贯通浅灰细线（`#CBD5E1`）。
   - **题目内容区**：从 `y = 15mm` 版心顶部起排。
3. **页脚区域（Footer）**：
   - 包含第几页/共几页、试卷编码，居中排布在版心底边下方 4mm 处。
   - 单页文档自动隐藏页码。

## 2.4 版式类型

| 版式 | 使用场景 | 约束 |
|---|---|---|
| 单栏 | 阅读、句子改写、综合题 | 默认版式 |
| 双栏 | 形近字、多音字、短小选择题 | 两栏内容必须独立完整 |
| 网格 | 看拼音写词语、田字格练习 | 格子尺寸统一 |
| 混合 | 多题型专项复习卷 | 各区域保持视觉连续性 |

不允许将所有题型强制转换为双栏。

选择版式时，优先考虑题目结构和书写需求，而不是页面剩余空间。

# 第三部分：字体与视觉设计系统

## 3.1 字体设计原则

低年级语文试卷应优先考虑：

- 中文字符清晰。
- 笔画结构容易辨认。
- 拼音符号完整。
- 生僻字和特殊符号不丢失。
- 数字、英文和中文混排协调。
- 打印后笔画不粘连。

字体选择必须考虑字体文件的实际可用性、字符覆盖率和授权条件。

不允许依赖操作系统随机字体回退。

正式 PDF 应嵌入所需字体，或使用经过验证的字体子集。

## 3.2 字体角色

建立统一字体角色：

| Token | 使用范围 |
|---|---|
| font-family-title | 试卷主标题 |
| font-family-body | 中文正文 |
| font-family-pinyin | 拼音与注音 |
| font-family-number | 数字和英文 |
| font-family-emphasis | 重点提示 |
| font-family-answer | 教师卷答案 |

字体角色与字号必须分开配置。

## 3.3 年级字号规范

以下为首期候选参数，需通过真实样卷和打印测试冻结。

| 内容 | 一年级 | 二年级 |
|---|---:|---:|
| 试卷主标题 | 20–24 pt | 20–22 pt |
| 一级题型标题 | 15–16 pt | 14–16 pt |
| 题目正文 | 12–14 pt | 11.5–13 pt |
| 拼音 | 11–13 pt | 10.5–12 pt |
| 辅助说明 | 10–11 pt | 10–11 pt |
| 答案解析 | 10.5–12 pt | 10.5–12 pt |
| 页码 | 9–10 pt | 9–10 pt |

基本原则：

1. 一年级优先保证阅读舒适度。
2. 二年级可以适当增加单位页面的信息量。
3. 不允许为了减少页数而整体缩小字体。
4. 不允许同一层级出现随意变化的字号。
5. 特殊题型可以单独定义字体尺寸。

## 3.4 行距规范

行距不能仅由字号决定，还要考虑汉字实际占用空间。

建议初始规则：

| 内容 | 行距 |
|---|---|
| 普通正文 | 字号的 1.5–1.8 倍 |
| 拼音题 | 字号的 1.6–1.9 倍 |
| 阅读文章 | 字号的 1.6–1.8 倍 |
| 答案解析 | 字号的 1.4–1.6 倍 |
| 标题 | 字号的 1.2–1.4 倍 |

行距最终以组件实际渲染效果为准。

## 3.5 颜色系统

采用适合黑白打印的灰阶视觉体系。

| Token | 用途 |
|---|---|
| color-primary | 主要文字 |
| color-secondary | 辅助文字 |
| color-border | 普通边框 |
| color-grid | 田字格线条 |
| color-divider | 分隔线 |
| color-background | 页面背景 |
| color-answer | 教师卷答案 |
| color-note | 辅助说明 |

设计要求：

- 正文保持高对比度。
- 田字格辅助线不能过重。
- 答题线打印后必须清晰。
- 教师卷答案可以使用颜色区分，但黑白打印仍须可识别。
- 不允许使用大量浅灰文字降低可读性。

## 4.2 组件契约

所有组件必须有统一的元数据。

建议使用如下结构：

```json
{
  "component_id": "tian_zi_grid",
  "version": "1.0.0",
  "supported_grades": [1, 2],
  "input_schema": {},
  "min_width_mm": 0,
  "preferred_width_mm": 0,
  "min_height_mm": 0,
  "splittable": false,
  "answer_mode": [
    "student",
    "teacher"
  ],
  "print_constraints": {},
  "visual_test": []
}
```

字段说明：

| 字段 | 说明 |
|---|---|
| component_id | 组件唯一标识 |
| version | 组件版本 |
| supported_grades | 支持年级 |
| input_schema | 输入数据结构 |
| min_width_mm | 最小宽度 |
| preferred_width_mm | 推荐宽度 |
| min_height_mm | 最小高度 |
| splittable | 是否允许拆分 |
| answer_mode | 支持的输出模式 |
| print_constraints | 打印约束 |
| visual_test | 对应视觉测试 |

实际项目中还应定义最大尺寸、可伸缩策略、测量规则和组件依赖。

## 4.3 田字格组件

### 设计要求

- 外框必须是正方形。
- 横线、竖线位置准确。
- 中线交点必须位于几何中心。
- 相邻田字格拼接时不能产生双重边框。
- 格子间距保持一致。
- 学生卷与教师卷的格子尺寸一致。

### 候选尺寸

| 参数 | 一年级 | 二年级 |
|---|---:|---:|
| 单格边长 | 12–15 mm | 10–13 mm |
| 格间距 | 0–1.5 mm | 0–1.5 mm |
| 外框线宽 | 0.6–0.8 pt | 0.6–0.8 pt |
| 内部辅助线 | 0.4–0.6 pt | 0.4–0.6 pt |

以上为待验证设计参数。

### 几何约束

假设格子边长为 L：

- 水平中线位置为 L/2。
- 垂直中线位置为 L/2。
- 对角线必须通过正方形对角顶点。
- 相邻格子之间的公共边只能渲染一次。

禁止通过缩放图片来模拟田字格。

应使用矢量线条或确定性绘制组件。

## 4.4 拼音组件

拼音是低年级语文试卷的重要组成部分。

要求：

1. 声母、韵母、声调符号完整。
2. 拼音必须与对应汉字正确关联。
3. 多音节词语应按音节排列。
4. 不能出现拼音与汉字错位。
5. 声调符号不能被裁切。
6. 字体必须支持带声调的拼音字符。

对于看拼音写词语：

- 拼音与答题格应建立明确对应关系。
- 多音节词语的格子数量必须与设计规则一致。
- 不能仅根据字符数量直接计算格子数量。
- 需要区分音节数量、汉字数量和词语长度。

对于给汉字注音：

- 注音位置应与汉字形成稳定对应。
- 不能让拼音漂移到相邻汉字。
- 不允许通过空格手工模拟对齐。

建议使用结构化音节数据，而不是直接将整段拼音作为普通字符串处理。

## 4.5 形近字组词组件

推荐使用双栏或多组网格布局。

设计要求：

- 每组汉字与对应答题区域保持关联。
- 汉字字号足够清晰。
- 组词横线长度适合实际书写。
- 不允许横线过短。
- 多组内容必须保持统一间距。

如果题目存在较长提示语，应自动退回单栏布局。

## 4.6 多音字组件

可使用：

- 单栏选择。
- 双栏选择。
- 词语与拼音对应表。

要求：

- 多音字与具体词语不能分离。
- 拼音选项之间保持清晰间距。
- 不允许选项跨栏错位。
- 选项整体作为不可拆分单元。

## 4.7 成语与词语补充组件

要求：

- 填空线长度足够。
- 多个成语保持统一结构。
- 不允许填空线与文字重叠。
- 需要考虑低年级学生实际书写字数。

如果答案区域过长，应优先采用独立行布局。

## 4.8 古诗组件

要求：

- 题目名称与诗句保持关联。
- 诗句按原有结构排版。
- 不允许为了节省空间任意改变诗句顺序。
- 填空线应与诗句位置对应。
- 诗句中的标点应保留。
- 教师答案不能改变原有诗句结构。

## 4.9 句子改写组件

要求：

- 题干独立呈现。
- 题干与答题区域尽量保持在同一页面。
- 书写区域必须满足完整句子作答。
- 多句作答应明确分行。
- 不允许把答题线压缩到不适合书写的长度。

## 4.10 阅读理解组件

阅读文章与对应题目应保持逻辑关联。

分页优先级：

1. 文章标题与文章正文保持关联。
2. 尽可能保持完整文章在同一页面。
3. 文章与对应题目尽量连续。
4. 如果文章必须跨页，应在合理段落边界分页。
5. 不允许题目出现在文章之前。
6. 不允许题目选项与题干随意分离。

阅读理解中的答题区域应根据题目类型决定：

- 选择题：选择区域。
- 判断题：判断标记。
- 简答题：多行答题区域。
- 词语解释：独立书写区域。

## 4.11 看图写话组件

看图写话应优先保证学生的观察和书写空间。

要求：

- 图片清晰。
- 图片比例正确。
- 图片不得被拉伸。
- 图片与题目要求保持关联。
- 书写区域足够大。
- 不允许为了节省页面而缩小图片和书写区域。

## 4.12 独立选择题组件 (Choice)

独立单选/多选题组件，面向全卷通用选择考查场景。

设计与排版要求：
- **选项自适应分栏**：排版引擎依据各选项最大文字长度动态计算排布列数：
  - 选项字长 $\le 6$ 字符：单行 4 列排布（`col-3`，每列 42mm）。
  - 选项字长在 $7\sim 14$ 字符：两行双列排布（`col-6`，每列 88mm）。
  - 选项字长 $> 14$ 字符或多行选项：单列整行通栏排布（`col-12`，每列 180mm）。
- **题干与选项绑定**：题干与选项组绑定为原子单元，具有 `keepWithNext` 约束，严禁在题干与选项之间断页。
- **双轨同构**：学生卷题干右侧保留括号槽 `（　）` 供学生作答；教师卷在括号槽内以 `#B3261E` 粗体红字显示标准答案字母（如 `（ A ）`），保持两者版面几何坐标 100% 同构（偏差 $\le 0.00\text{mm}$）。

## 4.13 独立判断题组件 (Judge)

独立判断对错题组件。

设计与排版要求：
- **陈述句与判断槽对齐**：陈述句左对齐排布，题目右侧预留弹性间距并固定右对齐放置带下划线的判断括号槽 `（　）`（宽度 14~18mm）。
- **双轨同构呈现**：学生卷判断槽留空；教师卷在括号中心绝对居中覆盖红字对错符号（如 `（ √ ）` 或 `（ × ）`），无任何多余布局漂移。

## 4.14 笔顺拆解与笔画填空组件 (StrokeOrder)

小学低段（尤其 G1/G2）核心特色题型，考查汉字笔画总数与特定笔顺名称。

设计与排版要求：
- **示范田字格引导演示**：左侧提供 12~14mm 规范示范田字格，以楷体清晰呈现目标考查汉字。
- **结构化填空槽**：右侧紧随填空题干，如：“‘水’共有（　）画，第二笔是（　）”。
- **双轨同构呈现**：学生卷填空槽预留 10~15mm 带下划线书写空间；教师卷以红字直接在填空槽原位显示笔画数字（如 `4`）或笔画符号（如 `㇇`）。

## 4.15 拼音连线题组件 (PinyinMatch)

拼音与词语、反义词、近义词等配对连线题型。

设计与排版要求：
- **行对齐物理布局**：左侧项（拼音/汉字）与右侧项（词语/图像）采用严格按行排列的 Flex 布局，并在中间预留至少 35~50mm 的安全连线通道。
- **物理锚点 (Match Dot)**：左侧文字右侧与右侧文字左侧各带有 1.6mm 实心圆点作为连线端点。
- **DOM 顺序与阅读顺序对齐**：为确保 PDF 文本提取（`pdftotext`）无歧义，每行按“左侧文字 → 左锚点 → 留白通道 → 右锚点 → 右侧文字”物理流式排列。
- **教师卷零侵入矢量红线**：
  - 学生卷：连线通道保持纯净空白，供学生使用铅笔手绘直尺连线。
  - 教师卷：在连线容器上方覆盖一层无交互、无布局占位的绝对定位 SVG 画布（`<svg class="match-svg">`），依据数据契约中的 `answer_pairs` 动态生成 0.35mm 细矢量实线（`stroke="#B3261E"`），精确连接左右端点。SVG 线条完全脱离文档流，对学生卷与教师卷的文本排版几何坐标产生 0.00mm 扰动。

# 第五部分：题型与版式映射规范

| 题型 | 对应组件标识 | 推荐布局 | 是否允许拆分 | 关键排版要求 |
|---|---|---|---|---|
| 看拼音写词语 | `pinyin_write_word` | 网格 | 否 | 拼音居中对齐田字格 |
| 给汉字注音 | `add_pinyin` | 单栏/双栏 | 按题目组 | 注音与汉字对齐 |
| 形近字组词 | `similar_character` | 双栏 | 按题目组 | 答题线长度统一 |
| 多音字辨析 | `polyphonic` | 双栏/单栏 | 按题目组 | 拼音注音与词语选项完整 |
| 成语补充 | `idiom_fill` | 双栏/网格 | 按题目组 | 填空横线宽度适中 |
| 古诗填空 | `poem_fill` | 单栏 | 否 | 诗句结构完整，上下句不割裂 |
| 句子改写 | `sentence_rewrite` | 单栏 | 否 | 提供 2~3 行充足书写空间 |
| 阅读理解 | `reading` | 单栏 | 特定段落允许 | 文章与题目紧密关联，支持内嵌子题型 |
| 看图写话 | `composition` | 单栏 | 否 | 配图居中清晰，方格纸或横线充足 |
| 独立选择题 | `choice` | 单栏/双栏/4栏 | 否（按小题） | 依据选项字长自适应分栏，题干与选项绑定 |
| 独立判断题 | `judge` | 单栏 | 否（按小题） | 右侧判断槽对齐，双轨绝对定位答案 |
| 笔顺拆解题 | `stroke_order` | 单栏/双栏 | 否（按小题） | 示范田字格引导，指定笔顺填空槽 |
| 拼音连线题 | `pinyin_match` | 双栏对齐 | 否（整题不可拆） | 左右锚点行对齐，教师卷 SVG 0.35mm 矢量实线 |

注意：

是否允许拆分必须由题目内部结构决定，不能仅由题型名称决定。

例如，阅读文章可以在段落边界拆分，但题目和对应选项不应随意拆分。连线题、古诗填空、看拼音写词语单个单元禁止跨页断裂。

# 第六部分：年级设计 Profile

## 6.1 一年级 Profile

一年级设计重点：

- 大字号。
- 大书写空间。
- 明确的题型边界。
- 简单的视觉结构。
- 较少的信息密度。
- 适当的视觉辅助。

建议配置：

```yaml
grade: 1

page:
  size: A4
  orientation: portrait
  margins_mm:
    top: 10
    bottom: 10
    left: 10
    right: 10

typography:
  body_pt: 13
  title_pt: 22
  section_title_pt: 16
  auxiliary_pt: 10.5

layout:
  default_columns: 1
  allow_two_columns: true
  prefer_large_answer_area: true

writing:
  tianzi_cell_mm: 14
  answer_line_spacing_mm: 10
```

以上为初始配置，必须经样卷验证。

## 6.2 二年级 Profile

二年级设计重点：

- 保持良好阅读体验。
- 适当提升页面信息密度。
- 支持更复杂的题型组合。
- 增加句子、阅读理解等题型的布局能力。

建议配置：

```yaml
grade: 2

page:
  size: A4
  orientation: portrait
  margins_mm:
    top: 10
    bottom: 10
    left: 10
    right: 10

typography:
  body_pt: 12
  title_pt: 21
  section_title_pt: 15
  auxiliary_pt: 10.5

layout:
  default_columns: 1
  allow_two_columns: true
  prefer_large_answer_area: true

writing:
  tianzi_cell_mm: 12
  answer_line_spacing_mm: 9
```

## 6.3 三年级扩展原则

首期不实现完整三年级排版配置。

但组件设计必须避免以下限制：

- 组件内部写死一年级字号。
- 组件内部写死二年级格子尺寸。
- 题型布局与年级配置耦合。
- 字体大小无法通过 Profile 调整。
- 页面空间无法适应更长阅读文章。

三年级应通过新增 Profile 和必要的组件扩展实现，而不是复制整套系统。

# 第七部分：智能布局与分页规范

## 7.1 基本架构

智能排版不能依赖浏览器自身的自动分页能力。

推荐流程：

```text
结构化试卷数据
      |
      v
题型识别与校验
      |
      v
年级 Profile 加载
      |
      v
组件映射
      |
      v
组件尺寸测量
      |
      v
页面空间预算
      |
      v
布局规划
      |
      v
分页决策
      |
      v
Layout Manifest
      |
      v
HTML / CSS 渲染
      |
      v
Chromium PDF
      |
      v
PDF 质量检测
      |
      v
最终交付
```

## 7.2 页面空间预算

布局引擎必须知道：

- 页面总高度。
- 上下边距。
- 页眉高度。
- 页脚高度。
- 当前已占用高度。
- 剩余可用高度。
- 当前组件最小高度。
- 当前组件推荐高度。

不能仅凭 CSS 自动判断页面是否还能放下题目。

## 7.3 组件布局约束

每道题应定义布局约束。

例如：

```json
{
  "question_id": "q001",
  "preferred_columns": 1,
  "splittable": false,
  "keep_title_with_content": true,
  "keep_question_with_answer_area": true,
  "minimum_answer_width_mm": 80,
  "answer_lines": 2,
  "page_break_priority": "normal"
}
```

约束应根据题型自动生成，也允许经过审核的人工配置覆盖。

## 7.4 分页规则

分页决策优先级：

1. 不拆分完整题目。
2. 不拆分题干与对应选项。
3. 不拆分题目与必要答题区域。
4. 尽可能保持同一题型模块连续。
5. 阅读文章优先按段落拆分。
6. 避免页面末尾只剩孤立标题。
7. 避免页面开头只有上一题的残余答题线。
8. 页面空间不足时允许增加页数。

**宁可多一页，也不能让题目残缺。**

## 7.5 分页失败处理

如果布局引擎无法完成排版：

- 尝试使用允许的替代布局。
- 尝试移动完整题目到下一页。
- 尝试增加页面。
- 尝试调整非关键间距。
- 如果仍然失败，返回明确错误。

禁止：

- 自动缩小所有字体。
- 任意缩小田字格。
- 删除答题空间。
- 隐藏溢出内容。
- 生成残缺 PDF 后仍报告成功。

`overflow: hidden` 不得作为解决内容溢出的手段。

# 第八部分：学生卷与教师解析卷双轨规范

## 8.1 基本原则

学生卷和教师卷必须共享同一份试卷结构数据。

两者不能分别生成两套完全独立的题目布局。

推荐结构：

```text
Question Data
      |
      v
Shared Layout Plan
      |
      +-------------------+
      |                   |
      v                   v
Student Renderer     Teacher Renderer
      |                   |
      v                   v
Student PDF          Teacher PDF
```

## 8.2 学生卷

包含：

- 题目。
- 题目说明。
- 分值。
- 必要的答题区域。
- 学生信息栏。
- 页码。

不包含：

- 标准答案。
- 参考解析。
- 教师批注。

## 8.3 教师解析卷

可以包含：

- 标准答案。
- 简要解析。
- 教学提示。
- 易错点。
- 评分说明。

解析深度分为：

| 级别 | 内容 |
|---|---|
| L1 | 标准答案 |
| L2 | 标准答案 + 简要解析 |
| L3 | 标准答案 + 教学解析 + 易错点 |

## 8.4 双轨布局一致性

要求：

1. 学生卷与教师卷题目顺序一致。
2. 题目编号一致。
3. 题目位置尽可能一致。
4. 答题区域在教师卷中可以填入答案。
5. 教师解析需要额外空间时，使用独立解析区域。
6. 不允许为了容纳解析而压缩学生卷原本的书写区域。

教师解析可能导致额外页面，这是允许的。

双轨一致性不意味着所有页面必须完全相同，而是题目结构、编号和定位必须能够追溯。

# 第九部分：PDF 渲染技术规范

## 9.1 首期技术路线

推荐：

**HTML/CSS + Chromium/Playwright + PDF。**

整体职责：

| 模块 | 职责 |
|---|---|
| Question Parser | 解析结构化试卷 |
| Component Mapper | 题型与组件映射 |
| Profile Loader | 加载年级配置 |
| Layout Engine | 尺寸测量与分页 |
| Layout Manifest | 记录最终布局 |
| HTML Renderer | 生成 HTML |
| CSS Design System | 控制视觉样式 |
| PDF Renderer | 输出 PDF |
| PDF Validator | 检查 PDF |
| Visual QA | 截图与视觉回归 |

## 9.2 技术职责边界

AI 可以负责：

- 识别题型。
- 理解题目结构。
- 选择候选组件。
- 提出布局建议。
- 识别潜在排版风险。

确定性引擎负责：

- 计算组件尺寸。
- 确定坐标。
- 计算页面空间。
- 执行分页。
- 生成 Layout Manifest。
- 输出最终 PDF。

CSS 负责视觉表现，不负责替代布局引擎完成复杂的业务分页决策。

## 9.3 物理单位

统一使用毫米作为布局系统的内部单位。

HTML 渲染时通过固定换算关系转换。

CSS 允许使用：

- mm：页面和几何尺寸。
- pt：字体和线条。
- px：仅限经过约束的屏幕显示或内部渲染细节。

不允许在不同模块中重复使用不同的换算算法。

## 9.4 PDF 输出要求

- 页面尺寸准确。
- 字体正确嵌入。
- 拼音字符完整。
- 文字不裁切。
- 图形不变形。
- 页面顺序正确。
- 页码正确。
- PDF 能够正常打开和打印。

每次正式生成必须记录：

- 试卷数据版本。
- 设计系统版本。
- 组件版本。
- 年级 Profile 版本。
- 渲染器版本。
- 字体版本。
- Layout Manifest 版本。

# 第十部分：质量检测与验收规范

## 10.1 五层质量体系

| 层级 | 检测对象 | 主要方法 |
|---|---|---|
| Q1 | 数据结构 | Schema、数据校验 |
| Q2 | 布局几何 | Layout Manifest、坐标检查 |
| Q3 | PDF 文件 | 字体、文本、页面尺寸检测 |
| Q4 | 视觉效果 | 页面截图、视觉回归 |
| Q5 | 实际打印 | 打印样张、人工审校 |

任何一层都不能完全代替其他层。

## 10.2 Q1：数据结构检测

检查：

- 题目 ID 是否唯一。
- 题目类型是否合法。
- 必需字段是否存在。
- 组件是否支持当前年级。
- 学生卷与教师卷引用关系是否正确。
- 是否存在无效布局配置。

## 10.3 Q2：布局几何检测

检查：

- 组件是否超出页面边界。
- 组件是否发生重叠。
- 答题区是否满足最小尺寸。
- 田字格是否符合几何要求。
- 题目与标题是否保持关联。
- 题目是否跨页异常。
- 页眉页脚是否与正文冲突。

## 10.4 Q3：PDF 文件检测

可以使用 PyMuPDF 等工具检测：

- 页面尺寸。
- 文本内容。
- 字体信息。
- 字符缺失。
- 文本边界。
- 图片边界。
- 页面数量。
- 页面内容是否异常缺失。

需要注意：PDF 文本边界检查不能完全判断视觉上的遮挡和排版问题。

## 10.5 Q4：视觉回归

建立固定标准样卷。

每次修改组件或设计参数后，重新生成 PDF 页面截图。

重点比较：

- 题目位置。
- 字体大小。
- 行距。
- 田字格几何。
- 答题线位置。
- 页间布局。
- 阅读文章分页。
- 教师卷答案位置。

视觉差异不能只依赖像素相似度判断。

对于字体抗锯齿等无实质影响的差异，应允许合理容差。

## 10.6 Q5：实际打印

正式出版级验收必须有实际纸面样张。

检查：

- 字体是否清晰。
- 田字格是否变形。
- 辅助线是否过淡。
- 答题线是否适合书写。
- 页面是否被打印机裁切。
- 黑白打印是否仍然易读。
- 双面打印是否存在内容干扰。

未完成实际打印验证，不得将规范标记为 PRINT_VALIDATED。

## 10.7 P0 阻断问题

出现以下情况时，不允许交付：

| 问题 | 处理 |
|---|---|
| 页面尺寸错误 | 阻断 |
| 题目内容丢失 | 阻断 |
| 文字越界 | 阻断 |
| 字体缺失 | 阻断 |
| 拼音乱码 | 阻断 |
| 田字格严重变形 | 阻断 |
| 答题区域不足 | 阻断 |
| 学生卷与教师卷题目错位 | 阻断 |
| 题目被意外拆分 | 阻断 |
| PDF 无法打开或打印 | 阻断 |
| 教师解析被裁切 | 阻断 |

## 10.8 P1 人工复核问题

以下问题需要人工检查：

- 页面空白是否合理。
- 题型标题是否统一。
- 字体大小是否舒适。
- 双栏布局是否平衡。
- 题目间距是否自然。
- 阅读文章是否容易阅读。
- 答题线是否足够。
- 灰度打印效果是否合适。

# 第十四部分：版本管理与变更控制

## 14.1 版本规则

采用语义化版本。

| 版本类型 | 适用情况 |
|---|---|
| PATCH | 文档修正、参数说明修正 |
| MINOR | 新增组件、增加兼容布局能力 |
| MAJOR | 修改核心数据契约、尺寸体系或分页机制 |

## 14.2 规范状态

| 状态 | 含义 |
|---|---|
| DRAFT | 草案 |
| VALIDATED | 已通过程序和样卷验证 |
| PRINT_VALIDATED | 已通过实际打印验证 |
| FROZEN | 当前版本冻结 |

冻结后的规范不能随意修改。

如果发现实际问题，应通过变更记录说明原因、影响范围和回归结果。

## 14.3 变更记录

每次修改至少记录：

- 修改内容。
- 修改原因。
- 影响组件。
- 影响年级。
- 影响文档类型。
- 回归测试结果。
- 是否需要重新打印。

# 第十五部分：最终设计原则

本规范的最终目标不是让试卷看起来更复杂，也不是让每张纸都填得满满当当。

而是建立一套能够稳定输出高质量小学语文练习卷的设计与工程体系。

必须坚持以下原则：

1. **先保证内容完整，再考虑页面利用率。**
2. **先保证学生能够阅读和书写，再考虑视觉装饰。**
3. **一年级与二年级使用独立配置，不强行统一。**
4. **题型使用标准组件，不依赖临时拼接 CSS。**
5. **布局引擎负责尺寸和分页，CSS 负责视觉表现。**
6. **学生卷和教师卷共享结构，保证题目对应关系。**
7. **程序检测不能代替人工审校。**
8. **没有实际打印验证，不宣称达到出版级标准。**
9. **新增能力必须有明确使用场景，不为了架构完整而增加复杂度。**
10. **已有能力优先复用，不重复建设。**
