# Profile 校准执行包（DRAFT → VALIDATED）

> 依据：`references/02-grade-profiles.md` 第 3 节、铁律 10（未做实物打样的参数一律标 DRAFT）。
> 当前状态：`grade-1.json` / `grade-2.json` 均为 **DRAFT**（设计基线，未经实物校准）。
> 本包把校准三步变成**可执行、可记录、可审计**的流程。三步全部通过才能把 Profile 的
> `status` 改为 `VALIDATED` 并写入校准日期与样本量——任何一步不过，改参数后**三步重跑**。

## 物料清单（打印前备齐）

| 物料 | 位置 | 用途 |
| --- | --- | --- |
| 硬件校准样张 | `build/standard-sample/print-review/print-calibration.pdf` | 第 1 步 样张实测（每台目标打印机 1 份） |
| 二年级试写卷 | `build/g2-review-u12/student.pdf`（4 页） | 第 2/3 步 真实题目试写 |
| 一年级试写卷 | `build/g1-pinyin-unit1/student.pdf`（2 页） | 第 2/3 步 真实题目试写 |
| 毫米钢直尺 / 游标卡尺 | 实物 | ±0.3mm 判读 |
| 记录表 | 本目录 `grade-1.md` / `grade-2.md`（打印或电子填写） | 全程记录与签署 |

## 第 1 步：样张实测（每台目标打印机 × 每个打印机 Profile）

1. 打印驱动必须选 **「实际大小 / 100% 缩放」**，严禁「适应纸张」。
2. 每台设备各打 1 份 `print-calibration.pdf`（覆盖 `default` / `inkjet-desktop` / `laser-compact` / `binding-left` 四种配置）。
3. 钢尺实测并填写样张内的**附录 B 签署表**，同时誊录到 `grade-1.md` / `grade-2.md` 的实测表。

**判定标准（全过才继续）：**
- 100mm 标定框横/纵误差 < 0.5%（即 ≥ 99.5mm）；若量出 96–97mm = 驱动自动缩放，先纠驱动。
- 10mm 规范边距内墨迹完好、无截断。
- 田字格 14mm / 12mm 长宽比 1:1（±0.3mm）。
- 0.18mm 十字虚线不断线。

**不通过的处置**：设备有底端盲区 → 在打印机 Profile 注入 `print_safety_margin: { bottom: N mm }` 后重打重测。

## 第 2 步：教师试写（每年级 2–3 位低段语文老师）

1. 用真实笔迹在试写卷上**手写完成全部答案**（不是检查，是做题）。
2. 按 `grade-N.md` 教师试写表逐题记录：书写空间够否、行距观感、字号观感、
   答案区是否够长、哪些题"写不下/需要挤行"。
3. 同步记录教学判断：分值结构、题目表述歧义、评分标准可执行性。

**判定标准**：无"写不下/挤行"记录，或问题定位到个别参数且有修正方案（记录后改 Profile → 重跑三步）。

## 第 3 步：儿童试写（每年级 ≥3 名目标学段学生）

1. 学生实际书写全卷，观察者逐题记录：
   - **出格**（写到格子/横线外的位置与次数）
   - **写不下**（写到后面挤行的位置）
   - **擦改**（擦改次数与原因）
   - 主观反馈（"格子太小/太大"等原话）
2. 三名学生的出格/写不下记录集中在同一参数上 → 该参数需要修正并重跑。

## 状态流转

```
DRAFT ──第1步过──第2步过──第3步过──► VALIDATED
  ▲                                      │
  └────── 任一步不过：修参数 ◄────────────┘
```

通过后执行：
1. `assets/profiles/grade-N.json` 的 `"status": "DRAFT"` 改为 `"VALIDATED"`，并追加
   `"validated": { "date": "YYYY-MM-DD", "printers": [...], "teachers": N, "children": N }`。
2. 同步更新 `SKILL.md` 年级基线表备注与 `references/02-grade-profiles.md`。
3. 校准样张 PDF、签署表扫描件归档到 `build/standard-sample/print-review/`（不入库）。

## 挂账说明

- 现场实测与真人试写**无法由引擎代劳**——本包只负责把工具、样张、记录表备齐。
- 校准样张本身的版式缺陷（右侧溢出、徽章语义、字号阶梯漂移）已于生成器内修复并重建。
