# 小学试卷题型视觉组件规范（v1.0）

> 2026-11-21 制定，以二年级语文复习卷（g2-review-u12）为验证样本。
> 定位：**不是给试卷换皮肤，而是建立小学试卷的题型视觉语言**——
> 组件机制跨年级、跨学科复用，具体布局、答题空间与视觉呈现按学科、年级、作答行为适配。
> 本规范与《质量三层验收规范》（QUALITY_ACCEPTANCE_SPEC.md）衔接：本文件定义"应该长什么样"，
> 三层验收判定"是否达标"。与《布局 AST 契约》（layout-ast.md）衔接：视觉改造以 AST 节点/字段承载。

## 0. 三条设计原则（不可妥协）

**原则 1：题型决定布局，而不是题目数量决定布局。**
同为 8 个空：量词走规整矩阵（fill_grid）、拼音走田字格网格（pinyin_row）、
选择题走选项列表（choice_options）。禁止用同一种"题干+横线"循环拼接所有题型。

**原则 2：答题区域由作答行为决定。**

| 作答行为 | 答题区域 | 引擎承载 |
| --- | --- | --- |
| 写一个汉字 | 一个田字格（含虚线十字中线） | `pinyin_row` / `stroke_order` |
| 写一个词语 | 按字数定宽的横线/词槽 | `word_pattern` 定宽槽 |
| 写一个拼音 | 适合拼音书写的注音槽 | `pin_annotation` |
| 选择/圈选 | 独立选项行 / 可圈选读音 | `choice_options` / `poly_circle_cells` |
| 写一个句子 | 整行书写横线（按 `lines` 数量） | `writing_lines` |
| 写一段话 | 连续方格（年级定格数格宽） | `composition_grid` |
| 填一个标点 | 定宽小槽（非整行长线） | `blank_slot("fixed")` |

**原则 3：视觉装饰不能影响学生做题。**
正文以黑（`--ink-1`）为主；大题编号用一种强调色（`--theme-primary` 暖橙，已有）；
示例/提示用浅底色（`--theme-soft`）；教师卷答案红字 + 位置区分，黑白打印必须可辨；
不滥用卡片、图标与装饰边框。任何底色不得干扰位图墨迹检测（浅暖灰已验证）。

## 1. 组件清单 P01–P12 与引擎映射

| 编号 | 组件 | 用途 | 引擎题型/节点 | 现状 |
| --- | --- | --- | --- | --- |
| P01 | 拼音书写 | 看拼音写词语 | `pinyin_write_word`（田字格）或 `fill_blank` 语境化（词语嵌入课文情境句，拼音括注+横线槽） | ✅ 达标：田字格与语境化双形态；复习卷优先语境化 |
| P02 | 横线填空 | 词语/句子填空 | `fill_blank`：stem 内嵌槽模式 + items 矩阵模式（`cols` 分栏） | ✅ 达标（v1.3 矩阵） |
| P03 | 选择题 | 单选 | `choice` / `reading.subs[sub_type=choice]` → `choice_options`（列数按最长选项自适应） | ✅ 达标 |
| P04 | 判断题 | 正误判断 | `judge` → 判断括号 | ✅ 达标 |
| P05 | 对照组词 | 形近字/多音字 | `similar_character`（两栏对照）+ `polyphonic`（读音并列/圈选） | ✅ 达标；对组强化（描边框）列入第二批 |
| P06 | 分类填写 | 词语归类 | `table_task`（表格式） | ✅ 可用；专用分类布局列入第三批 |
| P07 | 结构仿写 | ABB/AABB | `word_pattern`（例词+定宽词槽）；`style: "block"` 分类式单行块（加粗标签+示例+①②槽） | ✅ 达标（v1.5 分类式） |
| P08 | 古诗默写 | 古诗补充 | `poem_fill` → `poem`（诗题/作者分层 + 按字数定宽槽） | ✅ 达标（v1.4 作者行） |
| P09 | 句子仿写 | 句式/造句 | `sentence_rewrite`（例句块浅底 + 「仿写：」引导 + `scaffold` 填空句框/书写线） | ✅ 达标（v1.6 支架） |
| P10 | 连词成句 | 词语排序 | `sentence_order`（乱序词语 + 书写线） | ✅ 达标（v1.3 新增） |
| P11 | 阅读理解 | 短文阅读 | `reading`：passage 整块 + subs（填空/选择/判断/简答混排，`score` 逐题分值，`keep:"whole"` 整链分页） | ✅ 布局达标；"分区标签（读一读/选一选/写一写）"列入第三批（仅长阅读启用，小题 < 6 不分组） |
| P12 | 写话作文 | 低年级写话 | `composition`（要求 + 方格纸） | ✅ 基本达标；"写话提示 hints（可选提示块）"列入第三批 |

补充：`punctuation` 标点运用（v1.3 新增，定宽标点槽）、`stroke_order` 笔顺、`pinyin_match` 连线、
`add_pinyin` 注音、`idiom_fill` 成语（括号单字槽 / `slot: "grid"` 四字方格）、`table_task`、`flow_diagram` 为扩展组件池。

**工程约束（视觉改造必读）**：pdftotext 以 `-layout` 模式做线性抽取（P0-03 内容完整性校验依赖它），
任何块内**两行以上的并排分栏内容都会被跨列错序**——分类式块因此做成单行形态。
教师卷标记禁止改变块高（outline 画圈、绝对定位覆盖）。视觉参数一律 opt-in，默认输出逐字节不变（保黄金基线）。

## 2. 参数化配置（每组件支持）

题目数量（items/rows）· 每行数量（cols / 年级 Profile）· 答题区域大小（lines / rows）·
是否显示示例（samples / kind=imitate）· 是否显示选项（options）· 是否允许跨页（splittable / keep）·
字号字号（年级 Profile font_pt，组件层不得私改）· 分值位置（score → 题干后/小题行末）。

新增视觉参数的原则：**opt-in 字段，默认输出逐字节不变**（保黄金基线），改默认输出 = major 版本 + 重录基线。

## 3. 分批改造路线

**第一批：基础题型**（已完成 v1.4）
- ✅ 拼音书写：已是标准田字格对齐（无需改动，规范固化）
- ✅ 横线填空：矩阵模式（量词题 cols 分栏 + 括号留白）
- ✅ 多音字：新增 `mode: "circle"` 圈选式——读音并列、学生画圈、教师卷黑圈标答（outline 实现，双轨高度严格一致）；学校要求书写拼音时保留默认横线式
- ✅ 选择题/对照组词：现有布局符合规范（对照强化列入第二批）

**第二批：表达题型**（已完成 v1.5）
- ✅ 成语补充：`slot: "grid"` 四字方格槽（实字格 + 空白格，明确"每格一字"；教师卷空白格红字覆盖，灰度可辨）
- ✅ word_pattern 分类式：`style: "block"`——单行块 = **加粗标签** + 示例 + ①② 编号槽（圈号与槽必须同行；实测两行块会被 pdftotext -layout 跨列错序打断 P0-03 文本校验）
- ✅ 填空矩阵编号：fill_blank items 模式 `numbered: true`，圈号跨行连续（①-⑥）
- [ ] 古诗：诗句居中选项（`align: "center"` opt-in）
- [ ] 对照组词对组强化：同组描边/浅底，opt-in

**第三批：综合题型**（v1.7.0 部分完成）
- ✅ 量词/词语连线：`word_match` 类型（复用 match_board 连线板，pairs 自动错位，教师卷 SVG 覆盖）
- ✅ 插图支持：composition `q.image` 与 reading `passage.image`（src/height_mm/caption，与材料整链同页）——文档此前误记"不支持"，已修正
- ✅ 诗句居中选项：poem_fill `align: "center"`
- [ ] 阅读分区标签：subs 支持 `group` 字段（读一读/选一选/写一写），仅小题 ≥ 6 或多材料时建议启用
- [ ] 写话提示：composition 支持 `hints: []`（可选提示块，年级低/题目难时启用）
- **ABB 运用题**：无需新组件——紧随词语仿写出 `sentence_rewrite` 题（require 注明选上面写的词语造句），模式已写入 authoring-reference §5

**页面级组合**（持续）
- 页眉页脚模板统一（首页卷头 + 次页 running header 为教辅惯例，保持）
- 题目间距、分页策略、剩余空间管理由分页器承担；页面利用复核走三层验收 C-05

## 4. 验证约定

1. 每个视觉改造先落 AST 节点/字段（词汇表登记 + 保真说明），再用验证卷渲染，preview 逐页人工复核。
2. 教师卷任何标记不得改变块高（铁律 3）——**用 outline 画圈、绝对定位覆盖答案，禁止 border/文档流元素**（v1.4 圈选改造曾被 P0-07 拦截一次，即为案例）。
3. 改默认视觉 = major；改 opt-in = minor；每次变更记录进 layout-ast.md 版本沿革。
4. 视觉验收判定走《三层验收规范》C 层；物理打样与田字格量测保持人工。
