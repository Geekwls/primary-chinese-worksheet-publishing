# 试卷质量三层验收规范（v1.0）

> 2026-11-21 起执行。以 g2-review-u12 试卷外部审计为样本制定。
> 核心原则：**排版 PASS 不等于试卷合格**。内容、结构、视觉三层各自独立审计，
> 任一层不达标即不得交付，不存在"其他两层够好可以补偿"。

## 0. 三层定义与判定顺序

| 层 | 管什么 | 判定时机 | 依据 |
| --- | --- | --- | --- |
| **A 内容层** | 题目本身：知识点归属、正确性、指向、重复度、难度 | 写题后、渲染前 | 教材（逐字核对） |
| **B 结构层** | 分值体系、题型比例、小题分值、评分标准、难度梯度 | 写题后、渲染前 | 本规范 + 教学要求 |
| **C 视觉层** | 版面呈现：分页、对齐、答题空间、指令-样式一致 | 渲染后 | qa-report + preview 人工复核 |

执行顺序：A → B → `--check-only`（Q1）→ 渲染（C 自动项）→ preview 人工复核（C 人工项）。
A/B 层不通过的卷子**不得进入渲染**——排版引擎修不了内容错误。

## 1. A 内容层

| 编号 | 检查项 | 执行方式 |
| --- | --- | --- |
| A-01 | 知识点归属：每题能指到具体课文/园地，不引入未学内容 | 人工；写题时在 explain 注明出处 |
| A-02 | 课文引用逐字核对：标点在内，与教材原文一致；注明来源可追溯 | 人工核对教材；机器无法替代 |
| A-03 | 题目指向明确：题干指令与考查动作一一对应，一题一个指令 | 人工 |
| A-04 | 信息点查重：同大题内不得两题考同一信息（如阅读两小题都问"云"）；不同题允许同一知识点的不同技能（辨析 vs 提取） | 人工为主 |
| A-05 | 阅读考查边界：开放题标注"拓展"，明确是课文迁移还是独立阅读，材料须支撑可答 | 人工 |
| A-06 | 答案唯一或评分可判：开放题给出"答出其一即可"类判定口径 | 人工 |

**审计案例（g2-review-u12 v1）**：阅读第（2）（4）题都考"人们叫我云"（违反 A-04）；课文节选标点与教材不符（违反 A-02）。v2 已修复。

## 2. B 结构层

| 编号 | 检查项 | 执行方式 |
| --- | --- | --- |
| B-01 | 分值闭合：大题分值 = 小题分值之和；全卷 = total_score | 契约校验已拦总分（警告）；大题内和值**人工核算** |
| B-02 | 小题分值逐题标注：阅读 subs 用 `score` 字段；sentence_rewrite items 用 `score` 字段。**禁止把分值写进 stem 文本**（文本分值无契约约束，阅卷统计不可信） | 引擎已支持字段；全局校验待实现（先回填标准样卷，见 4 路线图） |
| B-03 | 评分标准可执行：主观题（仿写、阅读开放题、写话）explain 内给出分项评分（如"句式正确 2 分 + 通顺完整 2 分"） | 人工；explain 进教师解析页 |
| B-04 | 难度分层：识记类（拼音、默写、多音字）占比 ≤ 40%；须含理解运用类（语境选词、辨析）与表达类（写话） | 人工评估 |
| B-05 | 题型比例与考查目标匹配：专项卷不求大而全；综合复习卷覆盖该范围核心能力点 | 人工 |
| B-06 | 表达类任务合计占比不宜超过 30%（仿写+造句+写话），避免机械仿写堆叠 | 人工 |

**审计案例**：v1 句子仿写+写话合计 26 分且四道句子题全为主动仿写；阅读无小题分值；写话无评分细则。v2 重排为 28/20/16/26/10，补齐逐题分值与评分细则。

## 3. C 视觉层

| 编号 | 检查项 | 执行方式 |
| --- | --- | --- |
| C-01 | 指令与作答槽样式一致：题干说"括号里填"必须渲染括号槽；说"加点"必须真有点。**指矛盾即改题干或换组件，不许将就** | 人工看 preview（自动化待实现，见 4） |
| C-02 | 材料型题目跨页：阅读类设 `"keep": "whole"`；若整链超页回退拆分，需人工确认可接受 | 引擎已支持；preview 复核 |
| C-03 | 规整矩阵不拆行：fill_blank items 矩阵行已整链绑定；换页导致的大块空白由人工判断是否接受（P1-06） | 引擎已支持 |
| C-04 | 答题空间匹配：书写线行数与答案长度匹配（引擎有行数不足告警）；括号槽内不得再画横线 | 引擎告警 + 人工 |
| C-05 | 页面节奏：大块换页允许，但连续多页底部空白 > 100mm 时应调整 cols/rows 或题目顺序，而不是接受半页空 | P1-06 + 人工 |
| C-06 | P0 全过 + preview 逐页"挤、断、空"复核 + 教师卷答案不遮挡题面 | qa-report + preview 人工 |
| C-07 | 物理收口：目标打印机实物打样 + 田字格纸面量测（Q5，报告不覆盖项） | 人工 |

## 4. 路线图（自动化升级，按优先级）

1. **B-02 小题分值完整性进契约校验**：reading subs / sentence_rewrite items 缺 `score` 且 stem 无（N分）→ P1 警告。前置：给 `examples/g2-review-unit56.json` 回填小题分值（否则回归断言 warnings 为空会失败）。
2. **C-01 指令-槽一致性启发式检测**：stem 含"括号"且 fill_blank stem 模式渲染为线槽 → P1 警告。
3. **B-01 大题内分值和值校验**：section.score ≠ Σquestion.score → 警告。
4. **A-04 辅助查重**：同一 reading 的 subs 两两 stem 相似度提示（仅提示，判定留人工）。

> 明确**不做**自动化：A-02 课文核对（需要教材语料库，误报成本高于人工）、A-05/B-04/B-05（教学判断）。

## 5. 交付判定

- 任一 A 层项不达标 → 不出卷。
- 任一 B 层项不达标 → 不渲染。
- C 层：P0 全过 + P1 复核项逐条给出人工结论（接受/调整）， qa-report 存档。
- 三层结论写入交付说明；`DRAFT` 标记规则（铁律 10）不变。
