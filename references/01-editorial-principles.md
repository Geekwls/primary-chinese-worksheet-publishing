# 01 · 出版设计原则与儿童人体工学（L1）

> L1 只回答一个问题：**什么样的试卷才算合格**。它不定义字号，也不定义 CSS；它定义判断标准。
> 任何参数变更都必须回到这里找依据，而不是"看起来更好看"。

## 1. 使用者不是"小一号的成人"

低段（一至二年级，6–8 岁）的真实约束：

| 维度 | 能力特征 | 对排版的硬性要求 |
| --- | --- | --- |
| 视觉 | 视敏度与调节能力未成熟；对拥挤、细线、低对比不敏感 | 字号偏大、行距偏松、线条不细于 0.22mm、避免浅灰文字 |
| 书写 | 手部小肌肉控制弱；格子是"支架" | 田字格 11.5–13mm；书写行距 ≥9mm；答区不得被题干挤压 |
| 阅读 | 逐字认读，回视多；长句易断 | 题干尽量短、单句单要求；阅读正文通栏、行距 2.0 |
| 认知 | 需要明确的任务边界 | 一个大题一个指令；同页同类题靠拢；避免嵌套选项 |
| 注意 | 易被装饰干扰 | 不使用底纹、插图压字、彩色强调；层级靠字号与留白 |

## 2. 五项核心质量目标与验收依据

| 目标 | 核心要求 | 验收依据（可执行） |
| --- | --- | --- |
| 可读性 | 字体清楚、层级明确 | 字号/行距参数 + P1 视觉复核 |
| 可书写性 | 格子、横线、答题区足够 | 组件物理尺寸 + 纸面量测 |
| 可教学性 | 题目组织符合学习规律 | 教研审查（人工） |
| 可打印性 | 黑白清晰、无裁切 | 位图墨迹安全区 + 实物打样 |
| 可工程化 | 自动布局、可重复生成 | Layout Manifest + P0 全通过 |

**不使用"视觉美观评分"代替验收。** 一张卷子即使好看，只要孩子写不下、题目被截断、字体没嵌入，就是不合格。

## 3. 合格 / 不合格的判定线

算合格：

- 一道题的题干、作答区、分值、编号在同一视觉组内，未被分页劈开。
- 老师在纸质卷上能在预留区写完标准答案，不需要挤行。
- 黑白激光打印后，所有线条、格子、答案仍然可辨。
- 同一份数据重复生成，两次 PDF 的页面几何完全一致。

算不合格（任一命中即阻断）：

- 为压页数把田字格从 11.5mm 降到 10mm。
- 答案用浅灰或依赖彩色区分。
- 长答案被 `overflow:hidden` 裁掉，PDF 里看不出来但纸上缺字。
- 阅读文章被切成两页，第二页只剩两行。
- 只用"我看了一眼没问题"作为交付依据。

## 4. 常见反例（历史规范踩过的坑）

| 旧做法 | 为什么错 | 现在的做法 |
| --- | --- | --- |
| 上下边距 5mm，追求"多放题" | 家用打印机不可打印区常达 5–8mm，直接裁字 | 默认 12mm 安全区，边距可配置但不得低于验证值 |
| 固定"两页" | 题量一变就崩，只能靠缩字号硬塞 | 页数由内容决定，允许 3–6 页 |
| 固定 196/284mm 内容盒 | 与实际页边距、页眉页脚重复计算 | 由页面尺寸减边距推导，单一来源 |
| 所有解析压成一行 | 解析被截断，教学价值归零 | 解析允许换行，超额进独立解析页 |
| `overflow:hidden` 防溢出 | 把问题藏起来，印厂才发现 | 溢出必须暴露给验收 |
| CSS 模板直接改数字 | 一处改、处处漏 | 令牌 + Profile + 组件契约 |

## 5. 与 L2/L3/L4 的关系

- L1 提出的每个"感官要求"都必须能在 L2 找到对应令牌（如"格子要够大" → `geometry.tianzi_mm`）。
- L1 提出的每个"不能发生"都必须能在 L4 找到检测项（如"不能被裁切" → P0-02-T 墨迹越界）。
- 找不到对应令牌或检测项的要求，视为尚未落地，**不得写入已完成清单**。

新增年级或学科时，先扩写本文件的"能力特征"一栏，再去改参数。顺序反了，参数就会变成拍脑袋。
