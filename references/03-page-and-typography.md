# 03 · 页面物理尺寸、字体与视觉层级

> 原则：**页面几何只有一个来源（`assets/design-system/page.json` 的 `paper`），其余全部推导。**
> 三个容易混淆的量必须分清：浏览器 `@page` 边距、HTML 容器宽度、PDF 页面边界。本系统统一为 `@page margin:0` + 容器 210×297mm + 引擎绝对定位。

## 1. A4 页面模型

```text
┌────────────────────────────── 210mm ──────────────────────────────┐
│ ↕ 12mm 页边距                                                      │
│   ┌────────────────────── 186mm 内容宽 ──────────────────────┐    │
│   │  卷头（仅第 1 页）：标题 / 时间·满分 / 姓名·班级·得分      │    │  ↕ 内容区
│   │  ───────────────────────────────────────────────────────  │    │  高 264mm
│   │  正文块（绝对定位，x=12, width=186）                       │    │
│   │  ...                                                      │    │
│   └───────────────────────────────────────────────────────────┘    │
│   ↕ 3mm 间隙                                                       │
│   页脚：卷名 · 第 n 页 / 共 N 页                    高 6mm          │
│ ↕ 12mm 页边距                                                      │
└───────────────────────────────────────────────────────────────────┘
                           297mm
```

推导关系（改 `paper` 后自动生效）：

```text
content_width  = page_width  - 2 × margin_x        = 210 - 24 = 186
content_top    = margin_y                          = 12
content_bottom = page_height - margin_y - footer_h - footer_gap
               = 297 - 12 - 6 - 3                  = 276
可用内容高度    = 276 - 12                          = 264
```

## 2. 安全区与打印配置

| 配置 | 建议安全区 | 备注 |
| --- | --- | --- |
| 普通家用喷墨 | 12mm | 不可打印区常 5–8mm，且进纸有偏移 |
| 办公激光 | 10–12mm | 相对稳定，仍不建议低于 10mm |
| 专业印刷 + 裁切 | 12mm + 出血另计 | 需转 PDF/X，字体归一化 |
| 双面装订 | 内侧 15mm | 装订边单独加大，当前版本未实现"骑马钉镜像边距" |

**5mm 上下边距是历史错误配置，禁止直接复用。** 若必须压缩，先做目标打印机的实测打样，并把结论写进 Profile。

## 3. 字体角色

| Token | 用途 | 一年级 | 二年级 | 字重 |
| --- | --- | --- | --- | --- |
| `font.title` | 卷名 | 17pt | 16.5pt | 700 |
| `font.section` | 大题标题 | 13.5pt | 12.8pt | 700 |
| `font.question` | 题干 | 13.5pt | 12.2pt | 400 |
| `font.body` | 阅读正文 | 13pt | 11.6pt | 400 |
| `font.pinyin` | 拼音注音 | 11.5pt | 11pt | 400 |
| `font.hint` | 分值/提示 | 10.5pt | 10pt | 400 |
| `font.answer` | 教师卷答案 | 与对应正文一致 | 一致 | 600 + 红色 |
| `font.footer` | 页脚 | 8.5pt | 8.5pt | 400 |

层级建立规则：**只靠字号、字重、留白建立层级，不靠彩色底纹或装饰线。** 相邻层级字号差 ≥1.5pt，否则打印后看不出差别。

## 4. 字体清单（font registry）

生产环境必须固定字体文件，不依赖运行机器的随机回退：

```yaml
font_registry:
  chinese_body:
    family: "Noto Sans CJK SC"
    role: body
    required: true
  chinese_heading:
    family: "Noto Sans CJK SC"
    weight: 700
  pinyin:
    family: "Noto Sans"
    role: pinyin
    required_glyphs: [ā, á, ǎ, à, ē, é, ě, è, ī, í, ǐ, ì, ō, ó, ǒ, ò, ū, ú, ǔ, ù, ǖ, ǘ, ǚ, ǜ]
```

验收对应：

- 字体是否全部嵌入 → P0-04（`pdffonts` 的 `emb` 列必须全为 `yes`）。
- 声调字形是否真的存在 → P0-04-T（从 PDF 提取文本，逐个核对声调字符）。
- 具体字形是否被替换成方框 → 位图墨迹 + 人工抽检（自动检测无法可靠判定"豆腐块"）。

已知限制：Chrome/Skia 常把字体输出为 **Type 3**（每段文本一个子集对象）。办公打印与屏幕显示不受影响；若交付印厂，建议用 Acrobat / Ghostscript 归一化为 CID/TrueType 子集（验收会以 P1-08 提示）。

## 5. 颜色与灰度

| Token | 色值 | 用途 |
| --- | --- | --- |
| `ink.primary` | `#111827` | 正文 |
| `ink.secondary` | `#334155` | 次级文字、说明 |
| `ink.muted` | `#64748B` | 页脚、极弱信息 |
| `line.primary` | `#334155` | 主线条、格子框 |
| `line.secondary` | `#94A3B8` | 田字格虚线、辅助线 |
| `answer.teacher` | `#B3261E` | 教师卷答案 |
| `surface.base` | `#FFFFFF` | 页面底色 |

规则：

1. 全卷默认黑白可用，红色只用于教师卷答案这一种语义。
2. 灰度下 `#B3261E` 与 `#111827` 的明度差仍可辨；禁止用浅灰（≥`#999`）作为答案色。
3. 不使用彩色底纹区分题型；需要区分时用编号与留白。

## 6. 线宽

| Token | 值 | 用途 |
| --- | --- | --- |
| `lw.hair` | 0.18mm | 田字格虚线、方格内线 |
| `lw.thin` | 0.22mm | 注音槽、辅助下划线 |
| `lw.normal` | 0.30mm | 田字格外框、书写横线、括号槽 |
| `lw.strong` | 0.45mm | 卷头分隔线 |

细于 0.18mm 的线在 600dpi 激光打印上会断线或消失；粗于 0.5mm 的线会压迫低段学生的书写视觉。
