# 09 · 版本管理、扩展与旧规范处置

> 目的：避免后续 Agent 随手改规范、随手改参数，把"标准"变成"某次生成的结果"。

## 1. 三维独立版本号规则

不要将设计规范、数据契约与引擎实现绑定为同一个版本号，三者具有不同的演进周期：

| 版本常量 | 说明 | 演进对象 | 例子 |
| --- | --- | --- | --- |
| `SPEC_VERSION` | 设计规范手册版本 | `docs/DESIGN_SPECIFICATION.md` | 修改字号推荐区间、新增排版质量原则（如升级到 v2.1.0） |
| `LAYOUT_VERSION` | 布局清单数据契约版本 | `layout-manifest.json` 结构与坐标语义 | 布局清单新增字段、调整单位或坐标定义（如从 1.0.0 到 2.0.0） |
| `ENGINE_VERSION` | 排版引擎代码实现版本 | `src/` 代码实现、流水线、QA 质检器 | 优化分页算法、修复测量浮点误差、重构组件渲染（如 1.1.0） |

版本与文件映射：
1. `SKILL.md` 的 `metadata.spec_version`: 对齐 `SPEC_VERSION`。
2. `src/core/version.mjs` 中的 `LAYOUT_VERSION`: 写入每份 Layout Manifest。
3. `package.json` 中的 `version`: 对齐 `ENGINE_VERSION`。
4. `qa-report.json`: 同时记录 `SPEC_VERSION` 与 `LAYOUT_VERSION`。

## 2. 规范状态四态

| 状态 | 含义 | 允许的动作 |
| --- | --- | --- |
| `DRAFT` | 设计中/草案，待样卷验证 | 可自由修改 |
| `VALIDATED` | 已通过程序和样卷验证 | 修改需记录校准证据 |
| `PRINT_VALIDATED` | 已通过实际打印验证 | 冻结前置阶段 |
| `FROZEN` | 当前版本冻结 | 未经变更审查不得修改 |

当前状态：`assets/design-system/*` 与 `assets/profiles/*` 全部为 `DRAFT`，因为尚未完成实物打样与教师试写。

**铁律：未经实物打印验证的参数，不得标记为"出版级已验证"。** 写 `VALIDATED` 必须附：打样日期、打印机型号、样本量、量测记录。

## 3. 标准样卷（回归基线）

| 样卷 | 文件 | 覆盖 |
| --- | --- | --- |
| 二年级五、六单元复习卷 | `examples/g2-review-unit56.json` | 8 类组件、双栏形近字、通栏阅读、方格写话、双轨 |
| 一年级拼音与识字练习 | `examples/g1-pinyin-unit1.json` | 大字号、大格子、单栏、注音列 |

每次改组件或渲染器后，两份都必须重跑且 PASS；页数与块坐标的变化必须能解释。

扩展建议（尚未建立）：三年级阅读卷、纯字词专项、古诗专项、无解析学生卷、极限题量压力卷。

## 4. 扩展新年级 / 新学科的路径

**同年级内加题型**：写组件 → 登记契约 → 补示例 → 回归两份样卷。

**加三年级（同科）**：

- [ ] 补 L1 能力特征；新建 `grade-3.json`；新增三年级特有组件。
- [ ] 建三年级标准样卷；跑通 L3/L4。
- [ ] 回归一、二年级，确认无漂移。

**加数学/英语（跨学科）**：

- 复用：页面几何、字体层级、双轨机制、分页引擎、验收框架、Manifest 格式。
- 新建：学科组件库（竖式、线段图、四线三格、听力区）、学科题型注册表、学科验收规则（如数学公式行距、英语字母格线）。
- **不得**把语文组件改名后复用；答题方式不同，几何约束就不同。

## 5. 对旧规范（v2.0）的处置原则

不做整份废弃，也不做半升级，而是一次**规范重构**：

| 旧设计 | 处置 | 原因 |
| --- | --- | --- |
| A4 页面规格 | 保留，重新验证 | 物理尺寸正确 |
| 5mm 上下边距 | 修改为 12mm | 家用打印机不可打印区 5–8mm |
| 固定两页 | 删除 | 与题量解耦，页数由内容决定 |
| 固定 196mm 宽 | 修改 | 由页面尺寸与边距推导（186mm） |
| 固定 284mm 高 | 删除 | 未扣页眉页脚与内部留白，实际可用 264mm |
| 字体层级 | 保留并扩展 | 增加年级 Profile |
| 田字格尺寸 | 保留为候选参数 | 需实物打样确认 |
| 拼音逐音节对齐 | 保留 | 低段语文的核心规范 |
| 形近字双栏 | 降级为推荐布局 | 一年级必须单栏 |
| 所有解析一行 | 删除 | 不得牺牲解析完整性 |
| `overflow:hidden` | 禁止 | 掩盖溢出 |
| 双轨输出 | 保留并加强 | 增加统一 Manifest 与坐标级校验 |
| CSS 模板 | 重构为令牌 + 组件 + Profile | 消除散落魔法数 |

注意历史陷阱：`height:284mm` 配合 `box-sizing:border-box` 与 `padding-bottom:7.5mm` **并不等于**正文可用 284mm。真正可用高度必须扣除页眉、页脚、内边距与块间距，这是 v2.0 最隐蔽的错误。

## 6. 变更审查清单（改 Profile / 组件前必答）

1. 这次改动影响哪些年级、哪些题型？（列全）
2. 两份样卷是否需要重跑？页数会变吗？如果变，是"内容需要"还是"参数副作用"？
3. 验收规则需要新增或调整吗？（改规则必须说明为什么旧规则判不出来）
4. 版本号升哪一位？Manifest 里的 `layout_version` 是否同步？
5. 是否需要重新打样？（涉及线宽、字号、格子尺寸的任何改动：需要）
