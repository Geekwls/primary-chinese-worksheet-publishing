# 07 · 学生卷与教师解析卷双轨出版

> 双轨不是"同一份 PDF 加个答案开关"，而是**两个产品共享一份版面契约**。

## 1. 两份卷子的内容边界

| 内容 | 学生卷 | 教师卷正文页 | 教师卷解析页 |
| --- | --- | --- | --- |
| 卷名 / 时间 / 满分 | ✅ | ✅ | — |
| 姓名 / 班级 / 得分 | ✅ | ✅ | — |
| 题干、选项、分值 | ✅ | ✅ | 复述题干 |
| 作答区（格子/横线/方格） | ✅ 空白 | ✅ 答案覆盖 | — |
| 标准答案 | ❌ | ✅ 红色覆盖 | ✅ 文本 |
| 教学解析 / 易错点 | ❌ | ❌ | ✅ |
| 内部标签（题型、能力点） | ❌ | ❌ | 可选 |

## 2. 三种解析深度（不强制压成一行）

| 类型 | 适用 | 篇幅 |
| --- | --- | --- |
| 标准答案 | 字词、选择、填空 | 一行内 |
| 简短解析 | 多音字、形近字、句式 | 1–2 行 |
| 教学解析 | 阅读理解、综合运用、易错知识点 | 不限，进解析页 |

历史规范要求"名师点拨只能一行"是错误的工程限制：解析被截断等于没有解析。

## 3. 双轨一致性的实现方式

```text
同一份 parts（学生版 / 教师版） → 分别实测 → 高度必须逐块相等
                              ↓
        各自装箱 → 页数与每块坐标必须完全一致
                              ↓
     教师卷在预留空间内绝对定位作答，页面结构零变化
```

三条硬约束：

1. **零高度影响**：`.ans` 一律 `position:absolute`，父容器 `position:relative`。
2. **零坐标漂移**：教师卷不做任何"为了放答案而加高"的操作。
3. **溢出分流**：解析写不下时进独立解析页（`teacher.pdf` 末尾追加），不挤正文。

验收对应 P0-07：页数相等 + 每块 `(x, y, width, height)` 全等 + 实测高度差 ≤0.3mm。

## 4. 解析页规则

- 位置：`teacher.pdf` 正文页之后，页码连续（如学生卷 3 页，教师卷 3 + 2 页，页脚显示"共 5 页"）。
- 起始块：`参考答案与教学解析` 标题。
- 结构：题号 + 题干摘要 + 红字答案 + 灰字解析。
- 可跨页：解析块按题拆分（`splittable`），单题解析过长时整块换页。

## 5. 长答案的自动分行

教师在横线上书写时，答案按"每行可容纳字数"切分，优先在标点后断行：

```text
容量 = floor((content_width - 6mm) / (题干字号 × 0.3528 × 1.02))
二年级 186mm / 12.2pt → 约 41 字/行
```

若所需行数 > 预留 `lines`，引擎在契约警告中报出：

```text
教师卷答案预计需要 4 行，但只预留 3 行（q9 第3小题），请增加 lines 或缩短答案
```

处置顺序：加行 > 精简答案；**不得缩小答案字号**（会让教师卷与正文层级混乱，也违反"答案字号与正文一致"）。

## 6. 双轨产物的验收证据

| 证据 | 说明 |
| --- | --- |
| `layout-manifest.json` | 学生卷几何 |
| `layout-manifest-teacher.json` | 教师卷几何（含解析页） |
| P0-07 结论 | 逐块坐标一致性 |
| P0-09 结论 | 答案/解析文本是否完整出现在教师卷 |
| P0-11 结论 | 学生卷是否泄露答案 |
| `preview/teacher-*.png` | 目视核对红字是否压线、越格 |
