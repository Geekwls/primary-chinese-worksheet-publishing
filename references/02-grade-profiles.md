# 02 · 年级差异化设计 Profile

> 年级差异不是"两个字号变量"，而是一整套 Profile：字号、行距、格子、行距、栏数、每行数量。
> Profile 是数据文件（`assets/profiles/grade-*.json`），代码只读取，不得硬编码。

## 1. 一年级 · 启蒙书写型（Grade 1）

设计重点：拼音识读与注音、汉字规范书写、笔画笔顺、简单词句、看图写话。

| 参数 | 基线值 | 槽位键 | 说明 |
| --- | --- | --- | --- |
| 标题 | 17pt | `font_pt.title` | 卷名唯一视觉焦点 |
| 大题标题 | 13.5pt | `font_pt.section` | 与题干拉开 ≥1.5pt |
| 题干 | 13.5pt | `font_pt.question` | 与正文同级，避免"小字看不懂" |
| 阅读正文 | 13pt | `font_pt.body` | 行距 2.05 |
| 拼音 | 11.5pt | `font_pt.pinyin` | 需覆盖 ā á ǎ à 等 |
| 辅助说明 | 10.5pt | `font_pt.hint` | 分值、提示语 |
| 田字格 | 13mm | `geometry.tianzi_mm` | 手部控制弱，格子要足 |
| 注音槽高 | 5.5mm | `geometry.pinyin_slot_h_mm` | 用于导出版式对齐预留 |
| 书写行距 | 9mm | `geometry.writing_line_gap_mm` | 一行一句话 |
| 书写线宽 | 156mm | `geometry.writing_line_width_mm` | 不收满版心，避免越写越散 |
| 写话格 | 12mm | `geometry.composition_cell_mm` | 14 列；不得小于田字格 |
| 正上方注音字号 | 10.5pt | `font_pt.pinyin_annotation` | 与拼音行字号分开 |
| 注音字距 | 11mm | `geometry.pinyin_col_mm` | 必须容得下最长音节 |
| 每行词语 | 3 | `layout.pinyin_items_per_row` | 保持视觉不拥挤 |
| 形近字栏数 | 1 | `layout.similar_cols` | 单栏，一列一列读 |

## 2. 二年级 · 语言运用型（Grade 2）

设计重点：字词辨析、多音字、词语搭配、句式仿写、古诗积累、短文阅读。

| 参数 | 基线值 | 说明 |
| --- | --- | --- |
| 标题 | 16.5pt | — |
| 大题标题 | 12.8pt | — |
| 题干 | 12.2pt | 行距 1.85 |
| 阅读正文 | 11.6pt | 行距 2.0，通栏 |
| 拼音 | 11pt | — |
| 辅助说明 | 10pt | — |
| 田字格 | 11.5mm | 比一年级小 1.5mm，仍显著大于成人体感 |
| 书写行距 | 9mm | 句子改写下限；不得低于 9mm，否则与题干行距（7.96mm）无法区分 |
| 书写线宽 | 150mm | 通栏 186mm 会让二年级越写越散 |
| 写话格 | 10.5mm | 16 列；不得小于田字格 0.9 倍（10.35mm） |
| 阅读版心 | 165mm | 11.6pt 下约 37 字/行，优于通栏 45 字 |
| 正上方注音字号 | 9.5pt | 独立于拼音行 11pt，避免音节撑破字距 |
| 注音字距 | 10mm | 容得下 zhǎng 这类长音节 |
| 每行词语 | 4 | — |
| 形近字栏数 | 2 | 双栏但阅读题仍通栏 |

## 3. 这些数字是怎么来的、又该怎么改

现状标注：所有 Profile 的 `status` 均为 `DRAFT`，含义是"设计基线，尚未完成实物校准"。

校准三步（缺一不可）：

1. **样张实测**：用标准样卷打 3 份（家用喷墨 / 办公激光 / 专业印刷），量格子实际印刷尺寸（允许 ±0.3mm）。
2. **教师试写**：请 2–3 位低段语文老师用真实笔迹在答区写标准答案，记录"写不下/需要挤行"的题号。
3. **儿童试写**：一年级至少 3 名、二年级至少 3 名目标学生实际书写，观察出格、写到格子外、擦改。

三项通过后，把 Profile 的 `status` 改为 `VALIDATED`，并记录校准日期与样本量。**没有这三步，任何参数不得称"出版级已验证"。**

## 4. 扩展三年级（Step by Step）

不允许"复制 grade-2.json 改两个数字"就宣布支持三年级。按顺序做：

- [ ] 在 `references/01-editorial-principles.md` 增补三年级能力特征（含钢笔/中性笔书写、段落写作）。
- [ ] 新建 `assets/profiles/grade-3.json`（建议起始：题干 11.5pt、正文 11pt、田字格不用于正文、方格 8.5mm、书写行距 7.5mm、栏数 2）。
- [ ] 新增三年级特有组件（如 `paragraph_writing`、`word_explanation`），并在 `src/components/registry.mjs` 注册契约。
- [ ] 用三年级真实单元卷重建标准样卷，跑通 L3/L4。
- [ ] 回归：一、二年级样例必须仍 PASS，且页数、块坐标不得变化（除有意变更）。
- [ ] 更新 `SKILL.md` 的年级基线与 `--grade` 可用范围。

## 5. 反模式

| 反模式 | 后果 |
| --- | --- |
| 在组件函数里写 `if grade == 1: 13mm else 11.5mm` | 参数散落，改一处漏三处 |
| 用 CSS 媒体查询假装年级 | 年级是内容属性，不是视口属性 |
| 把教材版本和排版参数写进同一模块 | 换教材就要重写排版层 |
| 为压页数临时下调 Profile 值 | 参数失去统计意义，验收失效 |

Profile 只描述"呈现能力"，知识结构属于教材与教研，两者解耦是本系统的第一性要求。
