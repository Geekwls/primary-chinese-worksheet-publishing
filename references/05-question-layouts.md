# 05 · 题型布局规范与组件选择

> 关键判断：**由"作答方式 + 内容结构"决定组件，不由题型名字决定组件。**

## 1. 题型布局矩阵

| 题型 | 推荐布局 | 答题空间 | 拆页策略 |
| --- | --- | --- | --- |
| 看拼音写词语 | 网格（每行 3/4 词） | 田字格 | 行间可拆，单个田字格组不可拆 |
| 给加点字注音 | 单栏，字列横排 | 注音槽 | 整块不拆 |
| 多音字辨析 | 一/二年级 1/2 栏 | 选项 + 词语槽（18mm） | 行间不拆（splittable: false） |
| 形近字组词 | 一/二年级 1/2 栏 | 词语槽（18mm） | 行间可拆 |
| 成语补充 | 横排，3–4 个一行 | 括号单字槽 | 整块不拆 |
| 词语仿写 | 单栏，一例两空 | 词语槽 | 整块不拆 |
| 古诗填空 | 单栏，按诗句分行 | 行内下划线（按字数定宽） | 整块不拆 |
| 句子改写 | 单栏 | 整行横线 ×2 | 小题之间可拆 |
| 阅读理解 | 文章通栏 + 小题顺排 | 多行答区 | 文章不拆；小题之间可拆 |
| 看图写话/写话 | 单栏 | 方格纸（整块） | 整块不拆 |
| 独立选择题 | 自适应 1/2/4 栏 | 题干右侧括号槽 | 小题可拆，小题内部选项不拆 |
| 独立判断题 | 单栏 | 右侧固定对齐括号槽 | 小题可拆 |
| 笔顺拆解题 | 单栏 / 双栏 | 示范田字格 + 填空槽 | 小题可拆 |
| 拼音连线题 | 左右双列对齐 | 纯净连线通道（$\ge 35\text{mm}$） | 整题不拆 |

## 2. 组件选择判定树

```text
这道题要求学生"写"或"作答"什么？
├─ 写单个汉字（要规范笔顺/字形）
│   ├─ 有语音提示 → pinyin_write_word（拼音 + 田字格）
│   ├─ 有字形对比 → similar_character（字 + 组词槽）
│   ├─ 拆解笔画与笔顺 → stroke_order（示范田字格 + 笔顺填空）
│   └─ 句中空缺 → idiom_fill（括号单字槽）
├─ 写拼音（给汉字注音）
│   └─ add_pinyin（注音列 + 加点）
├─ 做匹配 / 连线
│   └─ pinyin_match（左右对齐 + 物理锚点 + 教师卷矢量红线）
├─ 做选项判定
│   ├─ 单选/多选题 → choice（自适应 1/2/4 列 + 题干括号槽）
│   └─ 对错判断题 → judge（陈述句 + 右侧对齐括号槽）
├─ 写词语/短语
│   ├─ 有样例模式 → word_pattern
│   └─ 句子成分 → generic（词语槽可后续扩展）
├─ 写句子
│   ├─ 有改写要求 → sentence_rewrite（整行横线）
│   └─ 自由表达（写话）→ composition（方格纸）
└─ 读文章再作答
    └─ reading（文章通栏 + 小题 + 答区）
```

## 3. 同一知识点、不同组件（必读反例）

"给加点字注音"有两种完全不同的排版需求：

| 形态 | 结构 | 组件 | 为什么不能混用 |
| --- | --- | --- | --- |
| 单字/词语注音 | 词语并排，目标字上方留槽 | `add_pinyin` | 需要垂直堆叠列，横向可换行 |
| 语段多音字注音 | 句子连续，注音嵌入字上方 | 需 `inline_pinyin_passage`（未实现） | 语段不能拆成词块，否则句子被切断 |

当前版本只实现了第一种。遇到语段注音题，**必须**：要么改命题形态，要么先实现新组件；不得用 `add_pinyin` 硬套成"把句子拆成一列一列的字"，那会破坏句子的连续性。

同理：

- "组词"在一年级是"字 + 一个槽"（单栏），在二年级是"两字两槽并排"（双栏）——同一个组件、不同 Profile 参数，不是两个组件。
- "古诗填空"的槽宽必须按答案字数计算；写死 26mm 会让"白日依山尽，{黄河}入海流"出现半个字的空档。

## 4. 排版决策优先级（冲突时按序）

1. 题目可读性（字号、行距、题干完整性）。
2. 书写空间（格子、横线、答区）。
3. 页面利用率（同类题靠拢、避免半页空）。
4. 页数最省。

**永远不允许**为了第 4 条牺牲第 1、2 条。压成两页不是目标，孩子写得下才是。

## 5. 视觉连续性规则

- 题干与其首行作答区必须同页（`q_head.keep_next = True`）。
- 阅读文章与第一道小题尽量同页；文章整体不跨页。
- 一个大题内的小题连续排布，不被别的大题插入（引擎按文档顺序装箱，天然满足）。
- 双栏只在"字词类"内部使用；阅读、句子改写、写话一律单栏。

## 6. 题量与页数的经验关系（二年级，12.2pt 题干）

| 题量 | 典型页数 | 备注 |
| --- | --- | --- |
| 6–8 题（专项） | 1–2 页 | 字词类可双栏压缩 |
| 9–12 题（单元复习） | 3–4 页 | 含 1 篇阅读 + 1 次写话 |
| 13–16 题（期末） | 4–5 页 | 阅读可到 2 篇 |

若实际页数明显偏离且内容无异常，先查 Profile 参数是否被临时改动，再查是否出现了不该拆的块被拆开。
